## 检索渠道不可用记录（防重复踩坑）

- 知乎全文转载（zhuanlan.zhihu.com/p/395683800 等）：WebFetch/curl 均 403。
- soujianzhu.cn 规范页：302 → 登录墙（MembersCenter/UserVerification）。
- 建标库站内搜索为 JS 动态加载，静态抓取只能走目录页取页 ID 的路径。
- 建标库"自2022年4月1日起废止的条文"页（GB 50367 book/1069/4692233.shtml）：正文 JS 加载，静态不可取——
  GB 55021-2021 对 GB 50367-2013 条文的废止清单**未核对**，M2 起以正式出版物补核。
- Morgain 全文版(morgain.com)、百度表单/文库、Scribd：超时/登录/查看器，不可提取。
