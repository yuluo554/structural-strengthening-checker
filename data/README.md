# data/ 数据台账

> 规则（ai-tool-project-sprint 阶段1）：每份数据登记来源与许可；规范条目挂出处+status；程序化自制带真值数据是核心资产（固定 seed 可复现，可注入已知缺陷做配对评测）。`_private/` 目录不入仓。

## 目录结构

| 目录 | 内容 | 入仓 |
|---|---|---|
| `knowledge/` | 机器可读知识库：条款库 `clauses/*.json`、规则库 `rules/*.json`、检查单 `checklist_gb55021.json`（schema 见 plan/04） | ✅（条目挂出处+status；**规范全文永不入仓**） |
| `cases/` | 验算算例库（真值+来源）；`pending/` 骨架不入基准 | ✅ |
| `cases/workings/` | 自编算例手工计算书（真值来源，可公开复核） | ✅ |
| `synthetic/` | 合成方案样本与真值（生成器在 src/datagen） | 样本少量 |
| `standards_raw/` | 规范原文获取渠道记录（不含全文） | ✅ 仅记录 |
| `_private/` | 规范全文等版权物本地留存 | ❌ gitignore |
