## PR-001 一般室内构件（正向）

输入：d=12mm，fy=300 N/mm²（HRB335 场景），αspt=0.8（场景系数），fbd=2.5 N/mm²（场景系数），
ψbr=1.00（其他构件），ψw=1.10（耐潮湿型胶粘剂取下限），ψT=1.00（环境温度 35℃≤60℃），
ψae=1.00（非抗震显式输入），ld=260mm。

1. ls = 0.2 × 0.8 × 12 × 300 / 2.5
   = 0.16 × 12 × 300 / 2.5
   = 1.92 × 300 / 2.5
   = 576 / 2.5
   = **230.4 mm**
2. ψN = 1.00 × 1.10 × 1.00 = **1.10**
3. 数值互证（第二渠道=逐项重算）：0.2×0.8=0.16；0.16×12=1.92；1.92×300=576.0；576.0÷2.5=230.4 ✓
4. 终判（M2 已核对式15.2.2-2）：ld_req = ψN·ψae·ls = 1.10×1.00×230.4 = **253.44mm**；
   ld=260 ≥ 253.44 → **满足**

## PR-002 反向例（提供的锚固深度不足）

输入：d=14mm，fy=360 N/mm²（HRB400 场景），αspt=0.7（场景系数），fbd=2.5 N/mm²（场景系数），
ψbr=1.00，ψw=1.10，ψT=1.00，ψae=1.00，ld=250mm。

1. ls = 0.2 × 0.7 × 14 × 360 / 2.5
   = 0.14 × 14 × 360 / 2.5
   = 1.96 × 360 / 2.5
   = 705.6 / 2.5
   = **282.24 mm**
2. ψN = 1.00 × 1.10 × 1.00 = **1.10**
3. 判定（M2 已核对式15.2.2-2）：ld_req = 1.10×1.00×282.24 = **310.464mm**；
   ld=250 < 310.464 → **需调整**（M1 期单调性预判与终判一致）
4. 数值互证：0.2×0.7=0.14；0.14×14=1.96；1.96×360=705.6；705.6÷2.5=282.24 ✓；282.24×1.1=310.464 ✓

## PR-003 悬挑构件（正向，受力状态系数加权）

输入：d=16mm，fy=360 N/mm²（HRB400 场景），αspt=0.9（场景系数），fbd=3.0 N/mm²（场景系数），
ψbr=1.50（悬挑结构构件），ψw=1.10，ψT=1.00，ψae=1.00，ld=600mm。

1. ls = 0.2 × 0.9 × 16 × 360 / 3.0
   = 0.18 × 16 × 360 / 3.0
   = 2.88 × 360 / 3.0
   = 1036.8 / 3.0
   = **345.6 mm**
2. ψN = 1.50 × 1.10 × 1.00 = **1.65**
3. 数值互证：0.2×0.9=0.18；0.18×16=2.88；2.88×360=1036.8；1036.8÷3.0=345.6 ✓；1.5×1.1=1.65 ✓
4. 终判（M2 已核对式15.2.2-2）：ld_req = 1.65×1.00×345.6 = **570.24mm**；
   ld=600 ≥ 570.24 → **满足**

## PR-004 查表算例（表15.2.3 + 表15.2.4，M2 追加）

输入：d=25mm，fy=360 N/mm²（HRB400），保护层 c=30mm，箍筋 φ8（锚固深度范围内间距 ≤100mm），
A 级胶，s1=160mm（=6.4d），s2=80mm（=3.2d），基材 C30（fc_grade=30），
ψbr=1.00，ψw=1.10，ψT=1.00，ψae=1.00，ld=520mm。

1. αspt（表15.2.3，已核对表值）：c=30、箍筋 φ8（"8或10"列，第 4 列）、d=25（行 2）→ **1.00**
   （行选择说明：d=25 为表列行值，无内插；列选择 c=30 精确命中）
2. fbd（表15.2.4，已核对表值）：A 级胶；行条件检验——s1≥7d=175？160<175 不满足；
   s1≥6d=150 且 s2≥3.0d=75？160≥150 ✓、80≥75 ✓ → 第二行（A 级，s1≥6d;s2≥3.0d）；
   基材 C30 列 → **4.0 N/mm²**
3. ls = 0.2 × 1.00 × 25 × 360 / 4.0 = 1800/4.0 = **450.0 mm**
4. ψN = 1.00 × 1.10 × 1.00 = **1.10**
5. 终判（式15.2.2-2）：ld_req = 1.10×1.00×450.0 = **495.0mm**；ld=520 ≥ 495 → **满足**
6. 数值互证：0.2×1.00=0.2；0.2×25=5.0；5.0×360=1800；1800÷4.0=450.0 ✓；450×1.1=495 ✓

## PR-005 查表反向例（B 级胶行限定 + 锚固不足，M2 追加）

输入：d=20mm，fy=360 N/mm²（HRB400），保护层 c=30mm，箍筋 φ8，
B 级胶，s1=110mm（=5.5d），s2=60mm（=3.0d），基材 C40（fc_grade=40，fc=19.1 为场景标注），
ψbr=1.00，ψw=1.10，ψT=1.00，ψae=1.00，ld=350mm。

1. αspt（表15.2.3）：c=30、箍筋 φ8、d≤20（行 1）→ **1.00**
2. fbd（表15.2.4）：**B 级胶仅可用第一行**（"A 级胶或 B 级胶，s1≥5d;s2≥2.5d"——第二、三行
   仅限 A 级胶）；s1=110 ≥ 5d=100 ✓、s2=60 ≥ 2.5d=50 ✓；基材 C40 列 → **4.0 N/mm²**
3. ls = 0.2 × 1.00 × 20 × 360 / 4.0 = 1440/4.0 = **360.0 mm**
4. ψN = 1.00 × 1.10 × 1.00 = **1.10**
5. 终判（式15.2.2-2）：ld_req = 1.10×1.00×360.0 = **396.0mm**；
   ld=350 < 396 → **需调整**
6. 数值互证：0.2×20=4.0；4.0×360=1440；1440÷4.0=360.0 ✓；360×1.1=396 ✓
