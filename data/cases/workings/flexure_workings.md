> 依据公式均已以正式出版文本核对（2026-10-05，记录与公式形态见

> 共同输入（各例重复列出）：Es=2.0×10⁵ MPa（HRB400 级常用值，**显式输入**）、εcu=0.0033、
> α1=1.0（C30，fc=14.3≤23.1）、保护层假设 as=35mm（受压侧 ap=35mm，仅 Asc>0 时参与）。
> ξb=0.518（HRB400、≤C50，GB 50010 公式 ξb=β1/(1+fy/(Es·εcu))=0.8/(1+360/(2e5×0.0033))，
> **场景输入系数**，非本工具代码断言）。数值保留 5 位有效数字，容差 ±0.5% 内与实现一致。

## 一、CFRP 布加固三例（式10.2.3-1~4、式10.2.8、表10.2.8）

通用量：h0=h−as=465mm；A=α1·fc·b=1.0×14.3×250=3575 N/mm；Mu0（原截面）：
x0=fy·As/A=360×1520/3575=153.07mm；Mu0=A·x0·(h0−x0/2)=3575×153.07×388.47=2.1257×10⁸ N·mm
=212.57 kN·m（式10.2.3-1 去 FRP 项与受压钢筋项）。

### CF-001 一次受力正向例（M0=0）

输入：Afe=101mm²，ff=2300（表4.3.4-1 高强度Ⅰ级布·一般构件），εf=0.01（表4.3.5 一般构件），
M=180 kN·m。

1. εf0=0（式10.2.3 符号说明：不考虑二次受力取 0）。
2. K=ff·Afe/εf=2300×101/0.01=2.323×10⁷ N（式10.2.3-2/3 联解的耦合系数）。
3. 式(10.2.3-2)+(10.2.3-3) 联立（ψf 未封顶）：
   3575x² − [T−K(εcu+εf0)]·x − 0.8·K·εcu·h = 0，T=fy·As=5.472×10⁵ N
   → 3575x² − 470541x − 3.06636×10⁷ = 0
   → x = [470541+√(470541²+4×3575×30663600)]/7150 = (470541+812341)/7150 = **179.42mm**
4. ψf=(0.8×0.0033×500/179.42−0.0033−0)/0.01 = (0.0073572−0.0033)/0.01 = **0.4057**（≤1.0，未封顶 ✓）
5. 式(10.2.3-1)：Mu=3575×179.42×(500−89.71) − 5.472×10⁵×35 = 2.63171×10⁸−1.9152×10⁷
   = **2.4402×10⁸ N·mm = 244.02 kN·m**
6. 检查：x=179.42 ≤ 0.85ξb·h0=0.4403×465=204.74mm ✓（式10.2.2）；提高幅度
   244.02/212.57−1=14.8% ≤ 40% ✓（式10.2.10）→ **满足**

### CF-002 二次受力例（M0=80 kN·m）

输入：Afe=133mm²，ff=2300，εf=0.01，M0=80，M=195。ρte=As/(0.5bh)=1520/62500=0.02432
（Ate=0.5bh，GB 50010；实现按此计算并在 warning 注明）。

1. 表10.2.8：ρte=0.02432 落在 0.020~0.030 档间 → αf=1.15+(0.02432−0.020)/(0.030−0.020)×
   (1.20−1.15)=**1.1716**（线性内插，实现决策 §六.1）；单排钢筋。σs0 未提供 → 不乘 0.9。
2. 式(10.2.8)：εf0=αf·M0k/(Es·As·h0)=1.1716×80×10⁶/(2×10⁵×1520×465)=9.373×10⁷/1.4136×10¹¹
   = **6.631×10⁻⁴**
3. K=2300×133/0.01=3.059×10⁷ N；T−K(εcu+εf0)=5.472×10⁵−3.059×10⁷×(0.0033+0.00066311)
   =5.472×10⁵−1.2123×10⁵=4.2597×10⁵ N
   3575x² − 425968x − 4.03788×10⁷ = 0 → x=(425968+871129)/7150 = **181.41mm**
4. ψf=(0.0072752−0.0033−0.000663)/0.01 = **0.3312**（未封顶 ✓）
5. Mu=3575×181.41×(500−90.71)−1.9152×10⁷ = 2.65444×10⁸−1.9152×10⁷ = **246.29 kN·m**
6. 检查：x ≤ 204.74 ✓；246.29/212.57−1=15.9% ≤ 40% ✓ → **满足**

### CF-003 反向例（加固量不足）

输入：Afe=50mm²，M0=0，M=260。K=2300×50/0.01=1.15×10⁷ N。

1. 3575x² − (5.472×10⁵−3.795×10⁴)x − 1.518×10⁷ = 0 → 3575x²−509250x−1.518×10⁷=0
   → x=(509250+690224)/7150 = **167.76mm**
2. ψf=(0.0078679−0.0033)/0.01 = **0.4568**（未封顶 ✓）
3. Mu=3575×167.76×(500−83.88)−1.9152×10⁷ = 2.49565×10⁸−1.9152×10⁷ = **230.41 kN·m**
4. M=260 > Mu=230.41 → **需调整**。需求量反算：式(10.2.3-1) 反解 x_M：
   3575x(500−x/2)=260×10⁶+1.9152×10⁷ → x²−1000x+156168=0 → x_M=193.68mm（≤204.74 可行）；
   式(10.2.3-2)：ψf(x_M)=(0.0068150−0.0033)/0.01=0.3515（未封顶）；
   Afe,req=(3575×193.68−547200)/(0.3515×2300)=145206/808.5=**179.6mm²**

## 二、粘钢板加固三例（式9.2.3-1~4、式9.2.9、表9.2.9）

通用量：h0=465mm；A=3575 N/mm；Esp=2.06×10⁵ MPa（Q235 常用值，**显式输入**）；
Mu0=212.57 kN·m（同上）。

### SP-001 一次受力正向例（Ap=600mm²，M0=0，M=190）

1. εsp,0=0。
2. K=Esp·Ap=2.06×10⁵×600=1.236×10⁸ N；T−K(εcu+εsp,0)=5.472×10⁵−4.0788×10⁵=1.3932×10⁵ N
   3575x²−139320x−1.63152×10⁸=0 → x=(139320+1533781)/7150 = 233.99mm
   ψsp=(1.32/233.99−0.0033)/(215/2.06×10⁵)=(0.005641−0.0033)/0.0010437=2.243 > 1.0
   → **封顶**：ψsp=1.0，力平衡退化为线性：x=(T+fsp·Asp)/A=(547200+215×600)/3575=676200/3575
   = **189.15mm**
3. Mu=3575×189.15×(500−94.57)−1.9152×10⁷ = 2.74148×10⁸−1.9152×10⁷ = **255.00 kN·m**
4. 检查：x=189.15 ≤ 204.74 ✓；255.00/212.57−1=20.0% ≤ 40% ✓ → **满足**

### SP-002 二次受力例（Ap=800mm²，M0=90，M=210）

1. ρte=0.02432 → 表9.2.9 内插 αsp=**1.1716**（同 CF-002 决策）；σs0 未提供。
2. 式(9.2.9)：εsp,0=1.1716×90×10⁶/(2×10⁵×1520×465)=**7.459×10⁻⁴**
3. K=2.06×10⁵×800=1.648×10⁸ N；T−K(εcu+εsp,0)=5.472×10⁵−1.648×10⁸×0.00404592
   =5.472×10⁵−6.6677×10⁵=−1.1957×10⁵ N
   3575x²+119568x−2.17536×10⁸=0 → x=(−119568+1767784)/7150 = 230.52mm
   ψsp=(0.0057259−0.0033−0.0007459)/0.0010437=1.610 > 1.0 → **封顶**
   x=(547200+215×800)/3575=719200/3575 = **201.17mm**
4. Mu=3575×201.17×(500−100.59)−1.9152×10⁷ = 2.87252×10⁸−1.9152×10⁷ = **268.10 kN·m**
5. 检查：x=201.17 ≤ 204.74 ✓（贴近限值）；268.10/212.57−1=26.1% ≤ 40% ✓ → **满足**

### SP-003 反向例（Ap=300mm²，M0=0，M=250）

1. K=2.06×10⁵×300=6.18×10⁷ N；T−Kεcu=5.472×10⁵−2.0394×10⁵=3.4326×10⁵ N
   3575x²−343260x−8.1576×10⁷=0 → x=(343260+1133298)/7150 = 206.51mm
   ψsp=(0.0063918−0.0033)/0.0010437=2.963 > 1.0 → **封顶** → x=(547200+215×300)/3575
   =611700/3575 = **171.10mm**

3. M=250 > Mu → **需调整**。需求反算：3575x(500−x/2)=250×10⁶+1.9152×10⁷ → x_M=184.68mm
   （≤204.74 可行）；ψsp(x_M)=(0.0071474−0.0033)/0.0010437=3.687>1.0 → 封顶 1.0；
   Asp,req=(3575×184.68−547200)/215=113033/215=**525.7mm²**

## 四、互证方式说明

   核对（formula_verification_M2.md），与建标库文字渠道不冲突；
2. **计算互证**：各例"联解→ψ 检查→封顶回代→承载力"双路径（未封顶二次解析解 vs 封顶线性解）
   由 ψ 值判断分支，互证包含于计算结构；Mu 的力平衡复核：A·x=fy·As+ψ·ff·Afe（未封顶时）
   逐例吻合（如 CF-001：3575×179.42=641427 ≈ 547200+0.4057×232300=641403，舍入差 0.004%）；
