## 一、数据 Schema

### 1.1 条款库条目（data/knowledge/clauses/*.json）

```json
{
  "clause_id": "GB50367-2013-8.2.3",
  "standard": "GB 50367-2013",
  "clause_no": "8.2.3",
  "title": "粘贴碳纤维布加固受弯承载力（要点标题）",
  "gist": "条文要点转述（自己的话，规避全文转载）",
  "excerpt": "关键句短摘录（≤2句，原文子串）",
  "formula_ref": "式(8.2.3-1)（编号以原文核对为准）",
  "symbols": [
    {"sym": "M", "meaning": "弯矩设计值", "unit": "kN·m", "range": [">0", null]}
  ],
  "limits": {"psi": {"op": "<=", "value": null, "note": "限值待核对，null=未入库"}},
  "source": {"channel": "官方/权威渠道名", "locator": "页码/条号定位", "checked_date": null},
  "status": "待核对",
  "tags": ["cfrp", "flexure"]
}
```

纪律：`status: "已核对"` 必须同时有 `source.checked_date` 非空；**无出处的值不得以确定语气落库**（引擎加载时校验，schema 校验进测试）。

### 1.2 验算参数卡（CalcInput，dataclass + JSON 互转）

四个模块共用结构 `{module: str, params: {sym: value}, meta: {name, date, note}}`，字段集按模块注册表定义：

| 模块 | 参数字段草案（符号: 含义 [单位]） | 待核对敏感字段 |
|---|---|---|
| `cfrp_beam_flexure` 碳纤维布加固梁受弯 | b,h 截面宽高 [mm]；fcu,fc 混凝土强度 [MPa]；As,fy 原受拉钢筋；Afe,fef,CFRP 有效截面/弹性模量 [mm²,MPa]；M0 初始弯矩（二次受力）；M 设计弯矩 [kN·m] | 应变滞后系数 ψ、二次受力折减、CEF 有效拉应变计算路径 |
| `steel_plate_flexure` 粘钢加固受弯 | b,h；fc；As,fy；Ap,fp（钢板截面/抗拉强度）；M0；M | 粘钢厚度上限、锚固长度构造 |
| `section_enlarge_flexure` 增大截面受弯 | b,h（原）；bf,hf（新增）；fc 原混凝土；fc2 新混凝土；As,fy；As2,fy2；M0；M | 新旧混凝土协同工作系数、界面处理构造 |
| `post_rebar_anchor` 植筋锚固深度 | fc；fy 植筋；d 直径 [mm]；la 基准锚固深度；混凝土/胶粘剂等级；群锚/边距条件 | 基材条件修正、JGJ 145 与 GB 50367 条款适用选择 |

每个字段带 `range`（合法范围，越界拒收）；`M0`（初始弯矩）是二次受力路径开关，`M0=0` 视为一次受力。

### 1.3 验算结论结构（CalcResult）

```json
{
  "module": "cfrp_beam_flexure",
  "inputs": {"echo": "全参数回显"},
  "steps": [
    {"no": 1, "formula_ref": "式(8.2.3-1)", "expr": "可读表达式",
     "values": {"symbol": 123.4}, "unit": "kN·m", "clause_ids": ["GB50367-2013-8.2.3"]}
  ],
  "capacity": {"value": null, "unit": "kN·m"},
  "ratio": {"value": null, "meaning": "效应比 M/Mu"},
  "verdict": "满足|不满足|需调整",
  "clauses_used": ["GB50367-2013-8.2.3"],
  "warnings": ["如：接近限值建议复核等（不改变判定）"]
}
```

> M2 实装增补（2026-10-05，见 plan/06 决策表）：CalcResult 增加 `metrics` 字段（扁平的可报告量
> 字典，如 `Mu_kNm / x_mm / psi_f / ld_required_mm`），供基准真值按名对账与报告导出取数；
> 其余字段形状不变。三态判定口径（M2 定稿）：满足=达标且全部限值检查通过；需调整=可通过调整
> 本方法参数达标（附调整方向与需求量）；不满足=本方法可行域内无法达标。

### 1.4 方案参数卡（PlanParamCard）

```json
{
  "doc": {"name": "方案.docx", "sha256": "..."},
  "methods": [{"name": "粘贴碳纤维布", "evidence": {"page": 3, "para": 2, "quote": "原文摘录", "is_quote_of_source": true}}],
  "materials": [{"kind": "混凝土|钢材|碳纤维|胶粘剂", "grade": "C30|Q355|I级…", "confidence": 0.0, "evidence": {…}}],
  "adhesive_indices": [{"index": "钢对钢拉伸抗剪强度标准值", "value": null, "unit": "MPa", "evidence": {…}}],
  "anchor_depth": [{"element": "植筋M12", "depth": null, "unit": "mm", "evidence": {…}}],
  "unloading": [{"required": true, "described": false, "evidence": null}],
  "crack_repair": [{"method": "…", "evidence": {…}}],
  "appraisal_first": {"present": false, "evidence": null}
}
```

解析纪律：每项值必须带 `evidence`，`quote` 非原文子串 → 丢弃该项并计入 `needs_confirm`（防幻觉，FR-B5）。

  "check_type": "param_range",
  "target": "adhesive_indices[index=钢对钢拉伸抗剪强度标准值]",
  "op": ">=", "limit_ref": "GB50367-2013-4.5.5",

### 1.7 基准真值 Schema

- 算例库（`data/cases/*.json`）：`{case_id, module, input{...}, expected{capacity±tolerance 或 verdict, ratio±tol}, source{书名/页码/例题号/渠道}, tolerance_policy}`；无 `source` 的条目加载即报错（测试锁死）。
- 合成方案真值（生成器输出）：`{doc_sha256, injected: [{rule_id, param, expected_verdict, also_expect:[…]}], clean_baseline: true}`——评测按"文档全部非 pass 集合"对账（同一注入隐含的其余结论记 `also_expect`，防误报口径漂移）。

## 二、模块接口（骨架签名）

```python
# core/clauses.py
class ClauseStore:
    def __init__(self, knowledge_dir: Path) -> None: ...
    def get(self, clause_id: str) -> Clause: ...
    def require_verified(self, clause_ids: list[str]) -> None:  # 未核对 → ClauseNotVerifiedError
    def status_summary(self) -> dict: ...

CALC_REGISTRY: dict[str, CalcModule]  # @register_calc 装饰器填充

# 三级判定 + 门控过滤 + 证据子串校验

# parsing/docx_text.py（惰性导入 python-docx）
def extract_text(docx_path: Path) -> list[Para]: ...      # Para{page?, index, text}

# report/docx_export.py（惰性导入 python-docx）
def export_calc_book(result: CalcResult, out: Path) -> None: ...

# bench/calc_bench.py, bench/check_bench.py
def run_calc_bench() -> BenchReport: ...   # 算例通过率（容差内）

```

## 三、错误处理与降级

| 场景 | 行为 |
|---|---|
| 条款未核对被请求进入计算 | `ClauseNotVerifiedError`（exit 3），消息指明先走核对流程 |
| 输入参数越界/缺字段 | `ValidationError` 逐字段列出（exit 2），GUI 侧表单红框 |
| docx/PDF 解析失败 | 报告"可解析段落 0"并整体降级 `needs_confirm` 清单，不产生任何 `fail` 结论 |
| extras 缺失（gui/report/parse） | 友好提示 + 安装命令，exit 2，无 traceback |
| LLM/网络 | 不存在（全离线），无此路径 |
