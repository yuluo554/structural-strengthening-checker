## 一、数据目录规划（与 data/README 台账联动）

| 目录 | 内容 | 入仓？ | 纪律 |
|---|---|---|---|
| `data/README.md` | 数据台账：每份数据来源+许可+sha256+status | ✅ | 唯一登记入口 |
| `data/knowledge/` | 机器可读条款库 / 规则库 / 检查单（JSON） | ✅ | 条目=要点+短摘录+出处+status；无出处不得以确定语气落库 |

| `data/synthetic/` | 合成方案样本 + 真值 JSON | 样本少量入仓示例，全量产物不入仓 | 生成器入 `src/.../datagen/`，固定 seed 可复现，产物 sha256 入台账 |

## 二、条文核对流程（数据可信度核心，写死为流程）

1. **定位**：按 01 §五 已查证的 4 本规范（GB 55021-2021 / GB 50367-2013 / GB 50550-2010 / JGJ 145-2013），先用检索确定"该查哪本规范哪个条号"（内部记忆只用于定位，不用于回答数值）；
2. **取原文**：官方/权威渠道获取条文原文（建标库等在线全文、地方引用文件、纸版），全文存 `data/_private/`（不入仓），渠道记入 `data/standards_raw/`；
3. **入库**：按 04 §1.1 schema 录条目——要点转述 + ≤2 句短摘录 + 出处（渠道+定位+日期）+ status=已核对；查不到 → status 保持"待核对"，**不得进入计算路径**；
4. **交叉核**：公式系数/限值与第二渠道对撞（不同渠道或条文说明算例反推），不一致 → 停用标记待仲裁；
5. **回写**：核对完成在 `data/README.md` 台账登记 sha256 与日期，并更新 00 状态表。

**熔断纪律**：同一数值两个渠道查不到/对不上 → 落"待核对"+记录已查渠道，继续推进其他条文，不允许停摆或反复自证。

## 三、算例库计划（验算基准真值）

| 来源类型 | 说明 | 登记 |
|---|---|---|
| 规范条文说明算例 | 4 个验算模块对应章节的条文说明例题 | 书名+版次+页码+例题号 |
| 公开教材算例 | 高校结构加固课程教材/注册结构考试真题解析（公开出版物） | 书名+作者+页码+例题号 |
| 交叉验证 | 同一算例尽量两渠道数值互证 | 台账记第二来源 |

- 容差策略：数值真值 ±0.5%（工程量纲），verdict 真值严格相等；容差理由写入 `tolerance_policy`；
- 目标规模：每模块 ≥3 例（一例一次受力、一例二次受力、一例"不满足/需调整"反向例），共 ≥12 例（M2 定稿）；
- 参数扫描回归：随机参数网格（固定 seed）→ 输出位级锁定（同输入必同输出），防实现漂移。

## 四、合成加固方案生成器（方案核查基准）

- 形态：`datagen/gen_plan.py`，python-docx 生成"加固方案"节选文档（检测鉴定结论/加固设计说明/材料要求/构造措施章节），**固定 seed**；
- 基线文档：全合规版本（`clean_baseline: true`）+ 每份注入 1-N 处已知错误；
- 注入错误类型（与规则库一一对应，rule_id 联动）：
  1. 胶粘剂安全性能指标低于限值（性能等级不足）；
  2. 锚固/植筋深度不足；
  3. 漏"先鉴定后加固"环节（鉴定结论缺失）；
  4. 构造措施缺失（卸载/支撑要求未提）；
  5. 材料强度等级标注不足（P1 扩展）；
  6. 裂缝修补方式与规范不符（P2 扩展）；
- 真值语义（一次定清，写进生成器模块注释）：注入项记主期望 `expected_verdict`；同一注入隐含的其余结论记 `also_expect`；评测按"文档全部非 pass 集合"对账——**多报 also_expect 之外的问题算误报**（误报 0 目标的口径）；
- 互斥坑当场记录：同一参数两处注入打架、多值封顶、先清旧行等；
- 产物：`docx + truth.json`（含 doc sha256），样本 3-5 份入仓示例，全量跑基准时现场生成（可复现，不背产物）。
