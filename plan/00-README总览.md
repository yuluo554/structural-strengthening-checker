**项目**：结构加固验算与加固方案核查桌面应用（土木工程·结构加固领域，Windows 桌面程序形态，**非识图路线**）

## 里程碑（初稿）

- M1 数据先行：规范条文库骨架（4 本规范条目表：编号/条号/公式/限值/原文摘录/status）+ 规范例题算例库（逐条登记来源）+ 合成加固方案生成器（植入参数错误真值）+ 数据台账
- M2 公式引擎：条款-公式-符号表结构化，4 个验算模块实现（单位制与容差设计），算例回归
- M3 方案核查：docx/PDF 文本解析 → 加固方案参数卡 → 限值/构造规则引擎（含类目门控）+ GB 55021 检查单
- M4 内置基准：算例通过率 100%（容差内）、核查检出率/误报率达标（误报 0）
- M5 桌面交付：PySide6 界面（验算表单/方案核查/检查单/报告）+ docx 导出 + PyInstaller 打包
- M6 脱敏发布 GitHub + Release（exe）+ 收尾固化
